ocmod.costaslabs.com PHP System Test (ENG)

system_test.php is a PHP script that you can run on your server
to ensure that CSV Price Pro import/export Module will work for you.

[INSTALLATION]

Use an FTP client to upload file "system_test.php" to root directory
of your website. Depending on your hosting, it may be named "public_html",
"www", "mainwebsite_html", "htdocs" or something like that.

When file is uploaded, open your browser and enter the following URL into
location bar: http://www.yoursite.com/admin/system_test.php
Replace "www.yoursite.com" with your own domain name.

The file will output the diagnostic results and give you further instructions.
